# Spec Driven Development Workflow

Every non-trivial change must follow:

## Phase 1 - Investigation

Understand:

- Current implementation
- Existing constraints
- Bottlenecks
- Risks

Deliverable:

investigation.md

---

## Phase 2 - Brainstorm

Generate alternatives.

For each alternative:

- Pros
- Cons
- Risks
- Validation strategy

Deliverable:

brainstorm.md

---

## Phase 3 - Specification

Define:

- Goals
- Non-goals
- Requirements
- Acceptance criteria

Deliverable:

spec.md

---

## Phase 4 - Implementation Plan

Create:

- Step-by-step execution plan
- Test strategy
- Rollback strategy

Deliverable:

plan.md

---

## Phase 5 - Implementation

Execute incrementally.

One measurable change at a time.

---

## Phase 6 - Validation

Run:

- Tests
- Benchmarks
- Regression checks

Document results.

Deliverable:

results.md

---

## Phase 7 - Decision

Choose:

- Keep
- Adjust
- Revert

Based on evidence only.
